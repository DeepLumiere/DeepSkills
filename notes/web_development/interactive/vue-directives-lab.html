⚡ Conditional Rendering: v-if / v-else vs. v-show DOM Destruction vs. CSS Display
Key Architectural Difference:
• v-if completely tears down and recreates event listeners and child components from the Real DOM tree.
• v-show always renders the element into the Real DOM tree and strictly toggles the CSS display: none; property.
🏆 High Distinction (v-if)

Exceptional academic performance! Score is ≥ 80.

📜 Passed Module (v-else-if)

Good effort. Score is between 50 and 79.

⚠️ Remedial Required (v-else)

Score is below passing threshold (< 50).

👁️ Visible via v-show (Inspect element in DevTools to see inline style="display: none;" when toggled off).

🛠️ Custom Vue Directives: v-focus & v-highlight Custom DOM Hook Extensions

Automatically calls el.focus() when the element is mounted into the DOM.

Inspects arguments and dynamic values to alter element styling.
