📖 Geolocation API Code Architecture

The W3C Geolocation API is accessed via navigator.geolocation. It provides three main methods: getCurrentPosition(), watchPosition(), and clearWatch().

if ('geolocation' in navigator) { const options = { enableHighAccuracy: true, timeout: 5000, maximumAge: 0 }; navigator.geolocation.getCurrentPosition( (pos) => { const { latitude, longitude, accuracy } = pos.coords; console.log(`Lat: ${latitude}, Lng: ${longitude}`); }, (err) => { console.warn(`Code ${err.code}: ${err.message}`); }, options ); }
Error Handling States:
  • PERMISSION_DENIED (1): User rejected location request.
  • POSITION_UNAVAILABLE (2): Network/GPS satellites unreachable.
  • TIMEOUT (3): Exceeded requested timeout limit.
💾 LocalStorage vs. SessionStorage Live Store Inspector Real-time Browser Key-Value Engine
LocalStorage: Persists data indefinitely until explicitly cleared (survives tab close and browser restarts).
SessionStorage: Persists data strictly for the lifespan of the browser tab / browsing context.
